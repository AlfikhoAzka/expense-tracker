# Expense Tracker

Expense Tracker is a Laravel-based web application designed to help users record, manage, and analyse their daily expenses.  
It provides a clean and simple interface to keep track of personal finances more effectively.

---

## Features

-  Add, edit, and delete transactions (income & expenses).
-  Monthly summary with charts.
-  Filter and search transactions by category or date.
-  User authentication (login & register).
-  Built with **Laravel 11** and **Tailwind CSS**.
